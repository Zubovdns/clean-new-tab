# Контекст проекта: Brave New Tab Extension

## 1. Основная цель проекта
Создание легковесного, быстрого, приватного и визуально привлекательного расширения для браузера **Brave** (а также других Chromium-браузеров), которое полностью замещает стандартную страницу **«Новая вкладка» (New Tab)** на собственный настраиваемый дашборд.

### Ключевые ориентиры:
* **Скорость открытия:** минимальное время загрузки вкладки (zero perceptible latency), локальный бандл без тяжелых внешних скриптов.
* **Приватность:** работа без сторонней телеметрии и без необходимости выдавать права на просмотр страниц пользователя (`<all_urls>`). Все настройки и заметки хранятся локально (`chrome.storage.local`).
* **Кастомизация:** удобный доступ к поиску, закладкам, виджетам и заметкам под персональные сценарии пользователя.
* **Современный стек:** React 19 + TypeScript + Vite + Tailwind CSS 4 с полноценным Hot Module Replacement (HMR).

---

## 2. Специфика работы с Brave Browser
Brave основан на движке Chromium, поэтому поддерживает спецификацию **Manifest V3 (MV3)**. Однако у Brave есть свои нюансы:

1. **Стандартная страница Brave:** по умолчанию Brave открывает собственный дашборд со статистикой блокировок трекеров и рекламы, часами и спонсируемыми фонами.
2. **Переопределение через `chrome_url_overrides`:**
   В `manifest.json` задается:
   ```json
   "chrome_url_overrides": {
     "newtab": "src/pages/newtab/index.html"
   }
   ```
3. **Настройки вкладки в Brave:**
   * Страница управления расширениями: `brave://extensions` (или `chrome://extensions`).
   * При первом открытии вкладки после установки расширения Brave может отобразить системный диалог безопасности: *«Это та страница новой вкладки, которую вы ожидали?»*. Необходимо нажать **«Сохранить изменения»** (*Keep changes*).
   * Если вкладка не подменилась автоматически, проверьте настройку в браузере: `brave://settings/newTab` -> пункт **«New tab page shows»** (должно быть разрешено отображение страницы расширения).

## 3. Архитектура и стек технологий

| Технология | Версия / Назначение |
|------------|---------------------|
| **Vite** | Сборщик и Dev-сервер с поддержкой HMR |
| **@crxjs/vite-plugin** | Интеграция Vite с расширениями Manifest V3 |
| **React** | 19.x — UI библиотека для компонентов |
| **TypeScript** | Строгая типизация компонентов, утилит и Chrome API |
| **Tailwind CSS** | v4 — Утилитарные стили и темная тема |
| **chrome.storage.local** | Персистентное хранение настроек пользователя с фолбэком на `localStorage` в DEV |

### Структура проекта:
```text
browser-new-tab/
├── manifest.json              # Базовый манифест расширения Manifest V3
├── manifest.dev.json          # Переопределения манифеста для режима разработки
├── vite.config.base.ts        # Базовый конфиг Vite (React, Tailwind, path aliases)
├── vite.config.chrome.ts      # Конфиг сборки под Chromium/Brave с плагином CRX
├── nodemon.chrome.json        # Конфигурация для watch-режима через nodemon
├── public/                    # Статические ассеты (иконки 32px, 128px)
├── src/
│   ├── assets/                # Стили и SVG-ассеты
│   │   └── styles/tailwind.css
│   ├── utils/
│   │   └── storage.ts         # Утилита для chrome.storage.local с localStorage fallback
│   └── pages/
│       ├── newtab/            # КЛЮЧЕВАЯ СТРАНИЦА: Замещение новой вкладки
│       │   ├── index.html     # HTML-контейнер страницы новой вкладки
│       │   ├── index.tsx      # Точка входа React (createRoot)
│       │   ├── Newtab.tsx     # Главный React-компонент дашборда новой вкладки
│       │   └── index.css      # Базовые стили
│       ├── popup/             # Всплывающее окно по клику на иконку в тулбаре
│       └── options/           # Страница настроек расширения (если потребуется)
└── dist_chrome/               # Результат сборки (папка, которую загружаем в Brave)
```

## 4. Разделение обязанностей и точек расширения

1. **`src/pages/newtab/Newtab.tsx`**:
   * Главный экран пользователя при открытии каждой новой вкладки (`Cmd+T` / `Ctrl+T`).
   * Содержит часы, дату, приветствие, поисковую строку, сетку быстрого доступа (быстрые ссылки) и виджет заметок.
2. **`src/utils/storage.ts`**:
   * Унифицированная обертка над асинхронным `chrome.storage.local`.
   * Гарантирует сохранение пользовательских ссылок, выбранного поисковика и заметок между сессиями браузера.
3. **`src/pages/options/` и `src/pages/popup/`**:
   * Вспомогательные страницы, которые можно использовать для тонкой настройки (например, выбор фонового изображения, интеграция с внешними API, импорт/экспорт закладок).
