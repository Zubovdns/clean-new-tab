# Clean New Tab 🚀

Минималистичное, быстрое и приватное расширение для браузеров **Brave**, **Google Chrome** и других Chromium-браузеров, заменяющее стандартную страницу «Новая вкладка» на организованный и чистый дашборд закладок.

---

## 🎯 Философия проекта

Большинство стандартных страниц новой вкладки перегружены: новостные ленты, виджеты погоды, навязчивая реклама, фоновые изображения и нерелевантный контент. **Clean New Tab** возвращает новой вкладке её главное предназначение — быть быстрым, сфокусированным трамплином для перехода к нужным ресурсам.

* **Минимализм и нулевой шум (Zero-distraction UI):** Никаких отвлекающих виджетов, баннеров или лент. Только ваши рабочие инструменты и закладки.
* **Секционная организация (Section-First):** Ссылки не сбиты в одну хаотичную кучу, а логично распределены по именованным секциям (*«Основное»*, *«Рабочее пространство»*, *«Медиа и отдых»* и др.).
* **Интуитивный Drag-and-Drop:** Полный визуальный контроль над структурой — перетаскивайте закладки внутри секции, перемещайте их между секциями и меняйте порядок самих секций на экране.
* **Мгновенная скорость (Zero perceptible latency):** Локальная загрузка страницы без внешних блокирующих запросов и тяжелых библиотек. Чистый React 19 и Tailwind CSS 4.
* **Приватность по умолчанию (Privacy-first):** Все данные и настройки хранятся исключительно на вашем устройстве в `chrome.storage.local`. Никакой телеметрии, аналитики и трекеров.
* **Нативный вид и адаптивность:** Лаконичный интерфейс в духе Google Material / Chromium с автоматической поддержкой темной и светлой темы (`prefers-color-scheme`).

## ✨ Возможности

* 📁 **Категории и секции закладок:**
  * Создание любого количества собственных секций.
  * Inline-редактирование заголовка секции в один клик.
  * Удаление секции с защитой от случайной потери данных, если в ней есть закладки.

* 🖐️ **Плавный Drag-and-Drop:**
  * Переупорядочивание секций на экране.
  * Перетаскивание закладок внутри одной секции.
  * Перенос закладок между разными секциями (как на определенную позицию, так и в конец секции).
  * Наглядные визуальные индикаторы зон вставки (Drop Indicators).

* 🌐 **Интеллектуальный движок фавиконок (Favicon Engine):**
  * Фоновый Service Worker сканирует открытые и активные вкладки (`chrome.tabs`), кэшируя подлинные браузерные иконки высокого качества.
  * Каскадный fallback: кэш Service Worker → Google FaviconV2 API (32px) → Chrome native `/_favicon/` → корень домена `/favicon.ico` → аккуратная карточка с первой буквой домена.
  * Возможность указать собственный URL фавиконки в окне добавления/редактирования.
  * Защита от утечек памяти: умный LRU-кэш на 200 записей без Base64-раздувания.

* ✏️ **Удобное управление ссылками:**
  * Быстрое добавление закладок с автоматическим определением протокола и заголовка по домену.
  * Контекстное меню у каждой карточки с возможностью редактирования и удаления.
  * Редактирование названия, адреса, целевой секции и иконки.
  * Поддержка закрытия окон и меню по клавише `Escape`.

* 🌓 **Адаптивная темная и светлая тема:**
  * Автоматическое переключение в зависимости от настроек операционной системы.
  * Выверенная палитра (темный графит `#202124` и чистый светлый фон) без мерцания при открытии новой вкладки.

## ⚡ Быстрый старт

### 1. Установка зависимостей
Требуется **Node.js >= 18** (рекомендуется LTS 20 или 22):
```bash
npm install
```

### 2. Режим разработки (HMR)
Запуск Dev-сервера с поддержкой **Hot Module Replacement**:
```bash
npm run dev
```
* Расширение автоматически компилируется в директорию `dist_chrome/`.
* При изменении кода компонентов в `src/` страница новой вкладки обновляется мгновенно без необходимости вручную перезагружать расширение в браузере.

Для фоновой пересборки через nodemon:
```bash
npm run dev:watch
```

## 🧭 Установка расширения в браузер

### Для Brave Browser:
1. Откройте в адресной строке:
   ```text
   brave://extensions
   ```
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (*Developer mode*).
3. Нажмите кнопку **«Загрузить распакованное»** (*Load unpacked*).
4. Выберите папку проекта:
   ```text
   clean-new-tab/dist_chrome
   ```
5. Нажмите `Cmd + T` (или `Ctrl + T`), чтобы открыть новую вкладку.
6. ⚠️ **Важно для Brave:** при первом открытии браузер может задать вопрос безопасности:
   > *«Это та страница новой вкладки, которую вы ожидали?»*
   
   Выберите **«Сохранить изменения»** (*Keep changes*).
7. Если страница не отобразилась, проверьте параметр в настройках: `brave://settings/newTab` -> пункт **«New tab page shows»** должен разрешать показ страницы расширения.

### Для Google Chrome / Edge / других Chromium:
1. Перейдите по адресу `chrome://extensions` (или `edge://extensions`).
2. Включите **«Режим разработчика»** (*Developer mode*).
3. Нажмите **«Загрузить распакованное»** (*Load unpacked*) и выберите папку `dist_chrome/`.
4. Откройте новую вкладку `Cmd + T`.
