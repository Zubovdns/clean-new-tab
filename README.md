# Clean New Tab Extension 🚀

Расширение для Chromium-браузеров (Brave, Chrome и др.), замещающее стандартную страницу «Новая вкладка» на персональный дашборд.

Построено на базе современного стека: **Vite**, **React 19**, **TypeScript**, **Tailwind CSS 4** и **@crxjs/vite-plugin** (Manifest V3).

> Полный архитектурный контекст и цели проекта описаны в документе [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md).

---

## ⚡ Быстрый старт

### 1. Установка зависимостей
Убедитесь, что у вас установлен **Node.js >= 18** (протестировано на Node 22):
```bash
npm install
```

### 2. Режим разработки (с живым HMR)
Запустите dev-сервер Vite:
```bash
npm run dev
```
* Плагин CRX автоматически соберет расширение в директорию `dist_chrome`.
* Включается **мгновенный Hot Module Replacement (HMR)**: при изменении файлов в `src/pages/newtab/` страница новой вкладки обновляется на лету без ручной перезагрузки!

> *Альтернатива:* если вам нужен классический режим фоновой пересборки при сохранении файлов:
> ```bash
> npm run dev:watch
> ```

## 🧭 Как подключить расширение в Brave

1. Откройте браузер **Brave**.
2. В адресной строке перейдите по адресу:
   ```text
   brave://extensions
   ```
   *(или `chrome://extensions`)*
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (*Developer mode*).
4. В появившейся панели нажмите кнопку **«Загрузить распакованное»** (*Load unpacked*).
5. В диалоговом окне выберите папку:
   ```text
   /Users/zubovdns/Developer/clean-new-tab/dist_chrome
   ```
6. Нажмите **Выбрать** (*Select*).
7. Откройте новую вкладку нажатием `Cmd + T` (или `Ctrl + T`).
8. ⚠️ **Важно для Brave:** при первом открытии браузер может показать вопрос безопасности:
   > *«Это та страница новой вкладки, которую вы ожидали?»*
   
   Нажмите **«Сохранить изменения»** (*Keep changes*).

Если вкладка не заменилась, проверьте настройки: `brave://settings/newTab` -> пункт **«New tab page shows»** должен разрешать отображение страницы расширения.

## 🏗️ Сборка в Production

Для создания оптимизированного production-бандла:
```bash
npm run build
```
Результат будет скомпилирован в папку `dist_chrome/`.

### Дополнительные команды:
* `npm run type-check` — проверка типов TypeScript (`tsc --noEmit`)
* `npm run lint` — запуск линтера ESLint

## 📁 Структура проекта

```text
clean-new-tab/
├── PROJECT_CONTEXT.md        # Детальный контекст, цели и роадмап проекта
├── manifest.json             # Конфигурация Manifest V3 для Chrome / Brave
├── vite.config.base.ts       # Базовый конфиг Vite
├── vite.config.chrome.ts     # Сборка под Chrome / Brave с @crxjs/vite-plugin
├── public/                   # Иконки расширения
├── src/
│   ├── assets/               # Стили Tailwind CSS и изображения
│   ├── utils/
│   │   └── storage.ts        # Обертка для chrome.storage.local с fallback
│   └── pages/
│       ├── newtab/           # ОСНОВНАЯ СТРАНИЦА (Новая вкладка)
│       │   ├── Newtab.tsx    # Главный React-компонент дашборда
│       │   ├── index.tsx     # Инициализация React (DOM root)
│       │   └── index.html    # Разметка страницы
│       ├── popup/            # Всплывающее меню по клику на иконку
│       └── options/          # Страница настроек
└── dist_chrome/              # Скомпилированное расширение (загружается в Brave)
```
